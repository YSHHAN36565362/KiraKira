# 선택: 스탬프 여행 노트

## Design Movement

일본 여행 안내서와 쇼와·헤이세이 시대의 문구 디자인에서 착안한 **에디토리얼 트래블 스크랩북**이다. 지도 기반 정보 서비스의 기능성을 유지하면서, 애니메이션 배경지 하나를 발견했을 때의 작은 설렘을 종이 지도와 수집형 스탬프의 언어로 풀어낸다.

## Core Principles

1. 정보는 명료하게 계층화하되, 각 장소에는 ‘발견한 장면’ 같은 감성적 여백을 부여한다.
2. 지도는 단순한 보조 위젯이 아니라, 카드 목록과 균형을 이루는 탐험의 중심축으로 둔다.
3. 사각형의 종이 조각, 얇은 선, 둥근 스탬프를 조합해 과한 장식 없이 수집의 즐거움을 표현한다.
4. 가벼운 종이 질감과 인쇄 오차를 연상시키는 미세한 그래픽 디테일로 촉각적인 깊이를 만든다.

## Color Philosophy

기본 배경은 오래 보관한 여행 노트의 **크림 종이색**으로 설정해 눈의 피로를 낮추며, 잉크 네이비는 긴 정보 탐색에서도 안정적인 가독성을 제공한다. 서비스의 소유 색상은 햇볕을 머금은 **살구색 ‘Kira Apricot’(#F56B4A)** 으로, 저장·검색·현재 위치가 아닌 ‘발견과 기억’의 행동만 따뜻하게 강조한다. 애니메이션, 영화, 드라마의 매체 구분은 산뜻한 청록·금잔화·라일락을 절제해 사용한다.

## Layout Paradigm

데스크톱에서는 화면을 정중앙에 쌓지 않고, 왼쪽의 가변적인 ‘여행 카드 서랍’과 오른쪽의 넓은 ‘지도 캔버스’가 맞물리는 **분할형 탐험 테이블**을 사용한다. 헤더 아래 검색 바는 종이 티켓처럼 길게 놓이고, 리스트는 독립 스크롤되며, 지도는 끊기지 않는 시각적 기준점이 된다. 모바일에서는 지도 요약판을 먼저 보인 뒤 카드 서랍이 아래로 이어져 자연스러운 세로 여행 동선을 만든다.

## Signature Elements

1. 지도 핀과 즐겨찾기 아이콘에 반복되는 살구색 원형 스탬프 모티프를 사용한다.
2. 섹션 제목과 카드 상단에는 얇은 점선 경로 및 짧은 좌표 표기를 사용한다.
3. 모달과 카드에는 잘라낸 종이 모서리처럼 보이는 작은 비대칭 접힘 장식을 한 곳에만 적용한다.

## Interaction Philosophy

각 상호작용은 목적지를 ‘펼치고, 찍고, 보관하는’ 감각을 준다. 카드에 마우스를 올리면 종이 조각이 아주 살짝 떠오르고 지도 핀과 연결되며, 즐겨찾기는 인위적인 폭발 효과 대신 스탬프가 찍히는 짧고 확실한 반응으로 처리한다. 키보드 탐색 시에는 명확한 잉크색 포커스 링을 항상 유지한다.

## Animation

모션은 160–240ms의 짧은 `cubic-bezier(0.23, 1, 0.32, 1)` 전환을 기본으로 사용한다. 검색 결과는 최대 60ms 간격으로 낮은 거리에서 페이드 인하고, 모달은 0.95 배율과 투명도에서 자연스럽게 나타난다. 카드, 필터, 버튼의 활성 반응은 0.97 배율 이하의 짧은 눌림으로 제한하며, `prefers-reduced-motion` 환경에서는 모든 비필수 모션을 제거한다.

## Typography System

헤드라인은 **Gowun Batang**의 온화한 세리프로 장소의 기억을 표현하고, 본문·탐색·폼은 **Pretendard** 계열의 고가독 산세리프로 정리한다. 서비스명은 대형 세리프와 작은 산세리프 보조 라벨을 조합하며, 작품명은 600–700 굵기, 설명·메타데이터는 400–500 굵기로 엄격히 구분한다. 영문 좌표와 날짜는 넓은 자간의 작은 대문자 스타일로 보조한다.

## Brand Essence

**키라키라 성지순례는 애니메이션과 영상 속 장면을 실제 여행의 기억으로 바꾸는, 작품 팬을 위한 장소 아카이브다.**

성격: **다정한, 수집적인, 안내자 같은**.

## Brand Voice

헤드라인은 감상적인 과장을 피하고 ‘발견’과 ‘장면’을 직접 연결한다. CTA와 마이크로카피는 짧고 친절하며, 사용자가 현재 할 수 있는 행동을 정확히 말한다.

예시 문구: “오늘, 장면 속 길을 따라가 보세요.”

예시 문구: “이 장소를 여행 노트에 담기”

## Wordmark & Logo

워드마크는 작은 별빛 두 점이 지도 핀 위에서 반짝이는 형태로, ‘키라키라’의 빛과 ‘성지순례’의 이동을 함께 암시한다. 심볼은 글자 없이도 인식되는 **살구색 핀 안의 두 개의 별**로 구성하며, 작은 파비콘에서도 식별 가능하도록 단순한 실루엣을 유지한다.

## Signature Brand Color

**Kira Apricot — #F56B4A**

## Style Decisions

- 아카이브 영역은 초기·빈 상태를 포함해 언제나 여행 카드 서랍과 지도 캔버스가 짝을 이루는 분할 탐색 테이블로 보이게 한다.
- 모든 주요 섹션 제목에는 점선 경로, 좌표형 마이크로 라벨, 스탬프 뱃지, 종이 접힘 중 하나 이상의 스크랩북 시스템 단서를 둔다.
- Kira Apricot(#F56B4A)은 탐색, 저장된 기억·스탬프 상태, 지도 핀에만 사용하고, 일반 탐색 요소는 잉크 네이비와 종이색으로 유지한다.
