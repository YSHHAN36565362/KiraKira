# 검증 기록

## 초기 정적 화면

- 정적 산출물 경로 `src/main/resources/static/index.html`에서 서비스명, 검색·필터, 장소 목록, 지도 캔버스, 빈 검색 상태가 렌더링되었다.
- Spring Boot API가 없는 미리보기 환경에서는 `/api/places` 응답을 빈 배열로 방어적으로 해석해, 사용자 친화적인 빈 상태를 표시했다.
- `/api/auth/me`가 사용자 객체가 아닌 응답을 반환하는 미리보기 환경에서는 이를 미로그인 상태로 처리해 헤더에 잘못된 사용자 이름이 노출되지 않았다.

## 지도 키 미설정 상태

- `YOUR_GOOGLE_MAPS_API_KEY`는 `#google-maps-config`의 `data-api-key`에 명시되어 있고, 실제 키로 교체될 때만 JavaScript가 Google Maps SDK를 동적으로 로드한다.
- 자리표시자 상태에서는 외부 SDK 오류 오버레이 없이, 스크랩북형 대체 지도와 “목록으로 장소를 안내합니다” 메시지가 남아 카드 탐색 흐름을 유지한다.

## 시각 점검

- 지도와 여행 카드 서랍의 분할 탐색 테이블이 초기·빈 상태에서도 항상 보인다.
- 헤더 좌표 라벨, 티켓 하단 경로 코드, 아카이브 라벨, 지도 캔버스의 좌표형 라벨로 여행 노트 시스템을 반복 적용했다.
